# Segundo Taller Parcial - Minería de Datos

## Descripción

Aplicación desarrollada en Shiny para la exploración y visualización de información de artículos científicos almacenados en una base de datos SQLite.

## Aplicación desplegada

https://3nhwp0-juan0andres-camacho0zarate.shinyapps.io/segundo-taller-parcial/

## Archivos del proyecto

- `app.R`: archivo principal de la aplicación.
- `ui.R`: interfaz gráfica.
- `server.R`: lógica del servidor.
- `data_manager.R`: funciones de acceso y manipulación de datos.
- `frontiers_big_data_2025.sqlite`: base de datos utilizada por la aplicación.
