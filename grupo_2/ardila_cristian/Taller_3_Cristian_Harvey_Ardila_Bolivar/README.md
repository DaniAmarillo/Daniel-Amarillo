# Taller 3 - Minería de Datos

## Disposición de archivos

```text
dm_2016325/
└── grupo_2/
    └── ardila_cristian/
        └── Taller_3_Cristian_Harvey_Ardila_Bolivar/
            ├── README.md
            ├── Taller 3 Completo.R
            ├── Taller 3 Minería de Datos.Rmd
            └── salidas/ (opcional, si no está, es generado por `Taller 3 Completo.R`)               
```

## Antes de ejecutar

El archivo `db_2026.csv`, el script `Taller 3 Completo.R` y el documento `Taller 3 Minería de Datos.Rmd` deben estar en la misma carpeta del taller.

La carpeta `salidas/` puede no existir al inicio.

## Ejecución completa

Abrir el archivo `Taller 3 Completo.R` con RStudio y ejecutarlo.

Luego abrir `Taller 3 Minería de Datos.Rmd` y ejecutar presionando **Knit**.

El script `Taller 3 Completo.R` lee la base de datos `db_2026.csv` y genera la carpeta `salidas/` con las tablas, gráficos y archivos auxiliares que usa el Rmd.

## Si `salidas/` ya existe

Si la carpeta `salidas/` ya fue generada previamente, se puede abrir directamente `Taller 3 Minería de Datos.Rmd` y presionar **Knit** para ahorrar el tiempo de ejecución de `Taller 3 Completo.R`.
